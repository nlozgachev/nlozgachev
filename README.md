TypeScript, React, and developer tooling at work. Rust, Swift, Go, Python, and PostgreSQL on the side. Most of my side projects are small, minimal tools built to solve a specific problem.

- **[pipelined](https://github.com/nlozgachev/pipelined)** — opinionated functional abstractions for TypeScript. Option, Result, Task, RemoteData, and more. Comes with thorough docs designed to make FP concepts accessible to developers at any experience level.
- **[mybad](https://github.com/nlozgachev/mybad)** — railway-oriented error handling for Go. Instead of checking errors after every step, you compose a pipeline of typed transforms. The first error short-circuits everything that follows; `Match` forces you to handle both outcomes before you can get a value out.
- **[sol](https://github.com/nlozgachev/sol)** — a keyboard-centric solitaire game for the terminal, written in TypeScript.
- **[nw](https://github.com/nlozgachev/nw)** — a net worth tracker CLI written in Rust. For those who prefer to self-manage long-term financial data with no frills: manual entry, no accounts linked, plain JSON storage.
