TypeScript, React, and developer tooling at work. Rust, Go, Python, and PostgreSQL on the side. Most of my side projects are small, minimal tools built to solve a specific problem.

- **[pipelined](https://github.com/pplnd/core)** — typed errors, explicit optional values, and composable pipelines for TypeScript. Data structures for explicit error handling, asynchronous workflows, and concurrency control.
- **[mybad](https://github.com/nlozgachev/mybad)** — railway-oriented error handling for Go. Eliminates repetitive error-checking boilerplate through composable, typed pipelines that short-circuit on failure and enforce handling at boundaries.
- **[nw](https://github.com/nlozgachev/nw)** — a minimal net worth tracker CLI written in Rust. Focused on long-term tracking with manual snapshot entry, multi-currency support, and plain JSON storage.
- **[sol](https://github.com/nlozgachev/sol)** — a keyboard-centric solitaire game for the terminal, built with TypeScript and `pipelined`.
- **[fnc](https://github.com/nlozgachev/fnc)** — an interactive CLI for conventional Git commits and branching, built with Go and `mybad`.
